# EVPAWBD4A nominal 3D body

`EVPAWBD4A_nominal.step` is a simplified model generated by `tools/build_evpaw_model.py`, not manufacturer CAD. It represents the nominal 3 × 2 mm body, 3.5 mm terminal span, and 0.6 mm overall height. Terminals, cover and actuator details are approximate; terminal cutouts, tolerances and internal construction are not modeled.

Source: Panasonic EVPAW terminal-with-cutout dimensional drawing, downloaded from [DigiKey](https://media.digikey.com/pdf/Data%20Sheets/Panasonic%20Electronic%20Components/EVPAW.pdf), page 3; retained in `hardware/verification/sw3-evpaw/EVPAW.pdf`. Panasonic's current reference is [ATK0000C364](https://industrial.panasonic.com/cdbs/www-data/pdf/ATK0000/ATK0000C364.pdf).

The library and placed SW3 both reference this project-local STEP with zero offset/rotation and unit scale. Z=0 is the seating plane, Z=0.6 is the nominal actuator top. KiCad handles the B.Cu transform. The native bottom-view render was inspected to confirm seating and orientation. The model is for visualization, not a substitute for physical fit qualification.
